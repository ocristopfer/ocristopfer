# Hi, I'm Cristopfer 👋

Developer from Brazil. I like self-hosting, homelabs and making game servers
run where they were never meant to run.

### What I'm working on

- **[game-server-deploy](https://github.com/ocristopfer/game-server-deploy)**:
  deploy SteamCMD dedicated servers to Proxmox LXC or Docker, with a web panel
  (monitoring, alerts, backups, config editor, mod manager) and a broker that
  creates instances and opens ports on OPNsense.
- **[RE-UE4SS · linux branch](https://github.com/ocristopfer/RE-UE4SS/tree/linux)**:
  the official UE4SS built for Linux dedicated servers, with Lua mods running
  on native Unreal servers (Palworld, Dragonwilds, ...).
  Mods in [ue4ss-mods](https://github.com/ocristopfer/ue4ss-mods).
- **[cockpit-sensors](https://github.com/ocristopfer/cockpit-sensors)**: every
  lm-sensors reading in Cockpit.
- **[proxmox-sensors](https://github.com/ocristopfer/proxmox-sensors)**: CPU, GPU,
  NVMe and HDD temperatures in the Proxmox VE summary, with a history chart.
